    Chapter 11

    變異數檢定

    兩個可以直接複製修改的 Python 模板： 單一母體變異數卡方檢定與兩母體變異數 F 檢定。

    先選你要哪一個

    • 一組資料，檢定母體變異數：Chi-square test。
    • 兩組資料，比較兩個母體變異數：F-test。
    這一章只需要記得：一個變異數用 χ²，兩個變異數相比用 F。

    11.1 單一母體變異數卡方檢定

    用來檢定一個母體的變異數是否等於指定值。 只要修改資料、H₀ 的變異數、α 與檢定方向。 

    import numpy as np
from scipy import stats

# =========================================================
# 模型 1：單一母體變異數卡方檢定
# H0: σ² = sigma2_0
# =========================================================

# ---------------------------------------------------------
# 使用者設定區：只需要改這裡
# ---------------------------------------------------------

data = np.array([
    10, 12, 9, 11, 13,
    10, 8, 12, 11, 14
], dtype=float)

# H0 中假設的母體變異數
sigma2_0 = 4

# 顯著水準
alpha = 0.05

# "two-sided"：H1: σ² != sigma2_0
# "greater"  ：H1: σ² > sigma2_0
# "less"     ：H1: σ² < sigma2_0
alternative = "two-sided"


# ---------------------------------------------------------
# 計算檢定統計量
# ---------------------------------------------------------

n = len(data)

sample_variance = np.var(
    data,
    ddof=1
)

df = n - 1

chi_square = (
    df * sample_variance
) / sigma2_0


# ---------------------------------------------------------
# 計算 p-value
# ---------------------------------------------------------

cdf_value = stats.chi2.cdf(
    chi_square,
    df=df
)

if alternative == "two-sided":

    p_value = 2 * min(
        cdf_value,
        1 - cdf_value
    )

    p_value = min(
        p_value,
        1.0
    )

elif alternative == "greater":

    p_value = 1 - cdf_value

else:

    p_value = cdf_value


# ---------------------------------------------------------
# 自動產生 H0、H1
# ---------------------------------------------------------

h0 = f"H0: σ² = {sigma2_0}"

if alternative == "two-sided":

    h1 = f"H1: σ² ≠ {sigma2_0}"

elif alternative == "greater":

    h1 = f"H1: σ² > {sigma2_0}"

else:

    h1 = f"H1: σ² < {sigma2_0}"


# ---------------------------------------------------------
# 自動判斷
# ---------------------------------------------------------

if p_value < alpha:

    decision = "拒絕 H0"
    conclusion = "有足夠證據支持 H1。"

else:

    decision = "不拒絕 H0"
    conclusion = "沒有足夠證據支持 H1。"


# ---------------------------------------------------------
# 輸出
# ---------------------------------------------------------

print("=== 單一母體變異數卡方檢定 ===")
print(h0)
print(h1)
print("樣本數 n =", n)
print("樣本變異數 =", round(sample_variance, 4))
print("自由度 df =", df)
print("χ² =", round(chi_square, 4))
print("p-value =", round(p_value, 6))
print("alpha =", alpha)
print("決策：", decision)
print("結論：", conclusion)

    11.2 兩母體變異數 F 檢定

    用來比較兩個獨立母體的變異數。 只要修改兩組資料、α 與檢定方向。 

    import numpy as np
from scipy import stats

# =========================================================
# 模型 2：兩母體變異數 F 檢定
# H0: σ1² / σ2² = 1
# =========================================================

# ---------------------------------------------------------
# 使用者設定區：只需要改這裡
# ---------------------------------------------------------

group1 = np.array([
    10, 12, 9, 11, 13,
    10, 8, 12
], dtype=float)

group2 = np.array([
    10, 11, 10, 9, 11,
    10, 9, 10
], dtype=float)

alpha = 0.05

# "two-sided"：H1: σ1² != σ2²
# "greater"  ：H1: σ1² > σ2²
# "less"     ：H1: σ1² < σ2²
alternative = "two-sided"


# ---------------------------------------------------------
# 計算樣本變異數與 F 統計量
# ---------------------------------------------------------

var1 = np.var(
    group1,
    ddof=1
)

var2 = np.var(
    group2,
    ddof=1
)

df1 = len(group1) - 1
df2 = len(group2) - 1

F_stat = var1 / var2


# ---------------------------------------------------------
# 計算 p-value
# ---------------------------------------------------------

cdf_value = stats.f.cdf(
    F_stat,
    df1,
    df2
)

if alternative == "two-sided":

    p_value = 2 * min(
        cdf_value,
        1 - cdf_value
    )

    p_value = min(
        p_value,
        1.0
    )

elif alternative == "greater":

    p_value = 1 - cdf_value

else:

    p_value = cdf_value


# ---------------------------------------------------------
# 自動產生 H0、H1
# ---------------------------------------------------------

h0 = "H0: σ1² / σ2² = 1"

if alternative == "two-sided":

    h1 = "H1: σ1² / σ2² ≠ 1"

elif alternative == "greater":

    h1 = "H1: σ1² / σ2² > 1"

else:

    h1 = "H1: σ1² / σ2² < 1"


# ---------------------------------------------------------
# 自動判斷
# ---------------------------------------------------------

if p_value < alpha:

    decision = "拒絕 H0"
    conclusion = "有足夠證據支持 H1。"

else:

    decision = "不拒絕 H0"
    conclusion = "沒有足夠證據支持 H1。"


# ---------------------------------------------------------
# 輸出
# ---------------------------------------------------------

print("=== 兩母體變異數 F 檢定 ===")
print(h0)
print(h1)
print("Group 1 樣本變異數 =", round(var1, 4))
print("Group 2 樣本變異數 =", round(var2, 4))
print("F =", round(F_stat, 4))
print("df1 =", df1)
print("df2 =", df2)
print("p-value =", round(p_value, 6))
print("alpha =", alpha)
print("決策：", decision)
print("結論：", conclusion)

    快速選擇

    • 一組資料 + 檢定變異數 → χ² 檢定。
    • 兩組獨立資料 + 比較變異數 → F 檢定。
    • p-value < alpha → 拒絕 H₀。
    • p-value ≥ alpha → 不拒絕 H₀。

    練習題

    1. 使用模型 1 檢定母體變異數是否等於 9。
    2. 將模型 1 改成右尾檢定，檢查母體變異數是否大於指定值。
    3. 使用模型 2 比較兩台機器的生產變異數是否不同。
    4. 將 alpha 從 0.05 改成 0.01，觀察結論是否改變。

    本章重點整理

    單一母體變異數使用 χ² 檢定；兩個母體變異數的比較使用 F 檢定。 程式只需要修改資料、H₀、α 與檢定方向即可直接使用。
