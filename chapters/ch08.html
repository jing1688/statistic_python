    Chapter 08

    區間估計

    使用 Python 計算點估計、z 信賴區間與 t 信賴區間， 並比較不同信心水準下的區間寬度。

    本章學習目標

    • 會使用樣本平均數與樣本標準差做點估計。
    • 會在母體標準差已知時建立 z 信賴區間。
    • 會在母體標準差未知時建立 t 信賴區間。
    • 會調整 90%、95% 與 99% 信心水準。

    0. 套件與範例資料

    import numpy as np
import matplotlib.pyplot as plt

from scipy.stats import norm, t

data = np.array([
    98, 102, 95, 100, 105,
    97, 103, 99, 101, 96
])

    1. 點估計

    點估計就是用樣本統計量估計母體參數。 最常見的是用樣本平均數估計母體平均數， 用樣本標準差估計母體標準差。 

    sample_mean = np.mean(data)

sample_std = np.std(
    data,
    ddof=1
)

print("樣本平均數：", sample_mean)
print("樣本標準差：", sample_std)

    2. z 信賴區間：母體標準差已知

    當母體標準差已知時，可以使用標準常態分配建立信賴區間。 

    x_bar = 100
sigma = 15
n = 25
confidence = 0.95

alpha = 1 - confidence

z_critical = norm.ppf(
    1 - alpha / 2
)

margin = (
    z_critical
    * sigma
    / np.sqrt(n)
)

lower = x_bar - margin
upper = x_bar + margin

print("z 臨界值：", z_critical)
print("誤差界限：", margin)
print("95% 信賴區間：", (lower, upper))

    也可以直接使用 norm.interval()：

    z_interval = norm.interval(
    confidence=0.95,
    loc=x_bar,
    scale=sigma / np.sqrt(n)
)

print(z_interval)

    3. t 信賴區間：母體標準差未知

    母體標準差未知時，改用樣本標準差， 並使用 t 分配。 

    sample_mean = np.mean(data)
sample_std = np.std(data, ddof=1)
n = len(data)

t_interval = t.interval(
    confidence=0.95,
    df=n - 1,
    loc=sample_mean,
    scale=sample_std / np.sqrt(n)
)

print("樣本平均數：", sample_mean)
print("樣本標準差：", sample_std)
print("95% t 信賴區間：", t_interval)

    4. 調整信心水準

    只要修改 confidence， 就可以比較不同信心水準下的區間。 

    for confidence in [0.90, 0.95, 0.99]:
    interval = t.interval(
        confidence=confidence,
        df=n - 1,
        loc=sample_mean,
        scale=sample_std / np.sqrt(n)
    )

    print(
        f"{int(confidence * 100)}% 信賴區間：",
        interval
    )
    信心水準越高，區間通常越寬。 因為你想更有把握地包住母體平均數，就得多留一點安全距離。

    5. 比較 z 與 t 信賴區間

    同一組資料下，t 區間通常會比 z 區間稍寬， 特別是在樣本數較小時。 

    x_bar = np.mean(data)
s = np.std(data, ddof=1)
n = len(data)

z_interval = norm.interval(
    confidence=0.95,
    loc=x_bar,
    scale=s / np.sqrt(n)
)

t_interval = t.interval(
    confidence=0.95,
    df=n - 1,
    loc=x_bar,
    scale=s / np.sqrt(n)
)

print("z 信賴區間：", z_interval)
print("t 信賴區間：", t_interval)

    6. 視覺化信賴區間

    使用 errorbar() 可以把平均數與誤差界限畫出來。 

    confidence_levels = [0.90, 0.95, 0.99]

means = []
margins = []
labels = []

for confidence in confidence_levels:
    alpha = 1 - confidence

    critical = t.ppf(
        1 - alpha / 2,
        df=n - 1
    )

    margin = (
        critical
        * sample_std
        / np.sqrt(n)
    )

    means.append(sample_mean)
    margins.append(margin)
    labels.append(
        f"{int(confidence * 100)}%"
    )

plt.figure(figsize=(8, 5))

plt.errorbar(
    x=labels,
    y=means,
    yerr=margins,
    fmt="o",
    capsize=6
)

plt.title("Confidence Intervals")
plt.xlabel("Confidence Level")
plt.ylabel("Estimated Mean")
plt.show()

    練習題

    1. 將 confidence=0.95 改成 confidence=0.99，觀察區間變化。
    2. 自行新增五筆資料，再重新計算 t 信賴區間。
    3. 將樣本數改大，觀察區間是否變窄。
    4. 比較 z 信賴區間與 t 信賴區間的寬度。

    本章重點整理

    • np.mean() 可計算樣本平均數。
    • np.std(..., ddof=1) 可計算樣本標準差。
    • 母體標準差已知時，可以使用 norm.interval()。
    • 母體標準差未知時，可以使用 t.interval()。
    • 信心水準越高，信賴區間通常越寬。
    • 樣本數越大，信賴區間通常越窄。
