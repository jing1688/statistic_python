    區間估計

    使用 Python 建立母體平均數與母體比例的信賴區間， 並估計指定誤差範圍所需的樣本數。

    本章學習目標

    • 會使用 Python 計算信賴區間。
    • 會區分母體標準差已知與未知時的計算方式。
    • 會使用 z 分配與 t 分配取得臨界值。
    • 會建立母體比例的信賴區間。
    • 會根據信心水準與誤差界限估計所需樣本數。

    0. 套件與範例資料

    這一章主要使用 NumPy 與 SciPy。 範例資料採用 25 輛節能車的每加侖英里數（mpg）。 

    import math
import numpy as np

n = len(mpg)
sample_mean = mpg.mean()
sample_std = mpg.std(ddof=1)

    使用樣本統計量估計母體參數時，可以直接先計算樣本平均數與樣本比例。

    母體平均數的點估計

    母體比例的點估計

    假設「成功」定義為 mpg 大於 100。 

    success = mpg > 100

    2. 母體標準差已知：z 信賴區間

    當母體標準差已知時，可以使用標準常態分配建立平均數信賴區間。

    取得 z 臨界值

    confidence_level = 0.95
alpha = 1 - confidence_level

z_critical = stats.norm.ppf(
    1 - alpha / 2
)

print("z 臨界值：", round(z_critical, 4))

    範例：穀片盒重量

    假設樣本平均重量為 1.02 磅、母體標準差為 0.03 磅， 樣本數為 25，計算 95% 信賴區間。 

    x_bar = 1.02
sigma = 0.03
n = 25
confidence_level = 0.95

alpha = 1 - confidence_level
z_critical = stats.norm.ppf(
    1 - alpha / 2
)

standard_error = sigma / np.sqrt(n)
margin_of_error = z_critical * standard_error

lower = x_bar - margin_of_error
upper = x_bar + margin_of_error

print("標準誤：", round(standard_error, 4))
print("誤差界限：", round(margin_of_error, 4))
print("95% 信賴區間：", (round(lower, 4), round(upper, 4)))

    封裝成函式

    def confidence_interval_mean_known_sigma(
    x_bar,
    sigma,
    n,
    confidence_level=0.95
):
    alpha = 1 - confidence_level

    z_critical = stats.norm.ppf(
        1 - alpha / 2
    )

    standard_error = sigma / np.sqrt(n)
    margin_of_error = z_critical * standard_error

    return {
        "lower": x_bar - margin_of_error,
        "upper": x_bar + margin_of_error,
        "margin_of_error": margin_of_error,
        "standard_error": standard_error,
        "critical_value": z_critical
    }
    result = confidence_interval_mean_known_sigma(
    x_bar=1.02,
    sigma=0.03,
    n=25,
    confidence_level=0.95
)

result

    5. 母體標準差未知：t 信賴區間

    母體標準差未知時，使用樣本標準差， 並以 t 分配的臨界值建立平均數信賴區間。

    不同自由度的 t 臨界值

    degrees_of_freedom = [2, 5, 24, 50]

t_table = pd.DataFrame({
    "df": degrees_of_freedom,
    "t_critical_95": [
        stats.t.ppf(
            0.975,
            df=df
        )
        for df in degrees_of_freedom
    ]
})

t_table

    建立 t 信賴區間函式

    def confidence_interval_mean_unknown_sigma(
    data,
    confidence_level=0.95
):
    data = np.asarray(data)

    n = len(data)
    x_bar = data.mean()
    sample_std = data.std(ddof=1)
    degrees_of_freedom = n - 1

    alpha = 1 - confidence_level

    t_critical = stats.t.ppf(
        1 - alpha / 2,
        df=degrees_of_freedom
    )

    standard_error = sample_std / np.sqrt(n)
    margin_of_error = t_critical * standard_error

    return {
        "sample_mean": x_bar,
        "sample_std": sample_std,
        "degrees_of_freedom": degrees_of_freedom,
        "critical_value": t_critical,
        "standard_error": standard_error,
        "margin_of_error": margin_of_error,
        "lower": x_bar - margin_of_error,
        "upper": x_bar + margin_of_error
    }

    節能車 mpg 的 90% 信賴區間

    mpg_result = confidence_interval_mean_unknown_sigma(
    mpg,
    confidence_level=0.90
)

mpg_result

    print(
    "樣本平均數：",
    round(mpg_result["sample_mean"], 3)
)

print(

    round(mpg_result["margin_of_error"], 3)
)

    6. 母體比例的信賴區間

    以超過 100 mpg 的車輛比例為例，建立母體比例的信賴區間。 

    success_count = np.sum(mpg > 100)
n = len(mpg)

p_hat = success_count / n

print("成功次數：", success_count)
print("樣本比例：", round(p_hat, 3))

    常態近似比例區間

    confidence_level = 0.90
alpha = 1 - confidence_level

z_critical = stats.norm.ppf(
    1 - alpha / 2
)

standard_error = np.sqrt(
    p_hat * (1 - p_hat) / n
)

margin_of_error = z_critical * standard_error

lower = p_hat - margin_of_error
upper = p_hat + margin_of_error

print("90% 比例信賴區間：", (round(lower, 3), round(upper, 3)))

    封裝成函式

    def confidence_interval_proportion(
    success_count,
    n,
    confidence_level=0.95
):
    p_hat = success_count / n

    alpha = 1 - confidence_level

    z_critical = stats.norm.ppf(
        1 - alpha / 2
    )

    standard_error = np.sqrt(
        p_hat * (1 - p_hat) / n
    )

    margin_of_error = z_critical * standard_error

    return {
        "p_hat": p_hat,
        "standard_error": standard_error,
        "margin_of_error": margin_of_error,
        "lower": max(0, p_hat - margin_of_error),
        "upper": min(1, p_hat + margin_of_error)
    }
    proportion_result = confidence_interval_proportion(
    success_count=7,
    n=25,
    confidence_level=0.90
)

proportion_result

    7. 估計母體平均數所需樣本數

    給定信心水準、預估標準差與可接受誤差， 可以反推最低樣本數。 

    def required_sample_size_mean(
    sigma,
    margin_of_error,
    confidence_level=0.95
):
    alpha = 1 - confidence_level

    z_critical = stats.norm.ppf(
        1 - alpha / 2
    )

    n = (
        z_critical * sigma
        / margin_of_error
    ) ** 2

    return math.ceil(n)

    假設要建立 90% 信賴區間，預估標準差為 10.5 mpg， 並希望誤差不超過 2 mpg： 

    required_n = required_sample_size_mean(
    sigma=10.5,
    margin_of_error=2,
    confidence_level=0.90
)

print("所需最低樣本數：", required_n)
    樣本數必須向上取整。因為抽 74.58 個人這件事，除非你的研究對象是樂高人，不然通常不太可行。

    8. 估計母體比例所需樣本數

    若沒有先前比例估計，通常可以使用 p = 0.5， 因為這會得到最保守、最大的樣本數。 

    def required_sample_size_proportion(
    p_estimate,
    margin_of_error,
    confidence_level=0.95
):
    alpha = 1 - confidence_level

    z_critical = stats.norm.ppf(
        1 - alpha / 2
    )

    n = (
        z_critical / margin_of_error
    ) ** 2 * p_estimate * (1 - p_estimate)

    return math.ceil(n)

    假設要建立 90% 信賴區間， 並希望誤差不超過 0.10： 

    required_n = required_sample_size_proportion(
    p_estimate=0.5,
    margin_of_error=0.10,
    confidence_level=0.90
)

print("所需最低樣本數：", required_n)

    9. 信賴區間涵蓋率模擬

    下面模擬重複抽樣 1,000 次， 查看 95% 信賴區間大約有多少比例會包含真正的母體平均數。 

    np.random.seed(123)

population_mean = 100
population_sigma = 15

sample_size = 25
n_sim = 1000
confidence_level = 0.95

alpha = 1 - confidence_level
z_critical = stats.norm.ppf(
    1 - alpha / 2
)

contains_mean = []

intervals = []

for _ in range(n_sim):
    sample = np.random.normal(
        loc=population_mean,
        scale=population_sigma,
        size=sample_size
    )

    x_bar = sample.mean()

    margin_of_error = (
        z_critical
        * population_sigma
        / np.sqrt(sample_size)
    )

    lower = x_bar - margin_of_error
    upper = x_bar + margin_of_error

    contains_mean.append(
        lower <= population_mean <= upper
    )

    intervals.append(
        (lower, upper)
    )

coverage_rate = np.mean(contains_mean)

print(
    "模擬涵蓋率：",
    round(coverage_rate, 3)
)

    畫出前 50 組信賴區間

    plt.figure(figsize=(9, 8))

for i, (lower, upper) in enumerate(intervals[:50]):
    plt.plot(
        [lower, upper],
        [i, i]
    )

plt.axvline(
    population_mean,
    linestyle="--",
    label="Population Mean"
)

plt.title("First 50 Confidence Intervals")
plt.xlabel("Interval")
plt.ylabel("Simulation")
plt.legend()
plt.show()

    練習題

    1. 已知樣本平均數為 106、母體標準差為 15、樣本數為 22， 計算 90% 與 99% 信賴區間。
    2. 將穀片盒範例的樣本數從 25 改成 16， 比較信賴區間寬度。
    3. 使用 mpg 資料建立 95% 的 t 信賴區間。
    4. 計算 mpg 大於等於 100 的比例信賴區間， 並比較 90% 與 95% 的區間寬度。
    5. 若希望 95% 信賴區間的誤差不超過 1.5， 且預估標準差為 12，計算所需樣本數。
    6. 將涵蓋率模擬次數增加到 10,000 次， 查看結果是否更接近 0.95。

    本章重點整理

    • stats.norm.ppf() 可以取得 z 臨界值。
    • 母體標準差已知時，可以使用 z 信賴區間。
    • 母體標準差未知時，可以使用 stats.t.ppf() 與 t 信賴區間。
    • 樣本數越大，信賴區間通常越窄。
    • 信心水準越高，信賴區間通常越寬。
    • 母體比例區間可以利用樣本比例與常態近似計算。
    • 指定誤差界限後，可以反推最低樣本數。
    • 重複抽樣模擬可以觀察信賴區間的長期涵蓋率。
